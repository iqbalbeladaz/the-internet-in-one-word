# The Internet in One Word

Entry for the make.fun bounty `u-ronigrv-the-internet-in-one-word-e388f33b`
("The Internet in One Word", $10): describe the whole internet in a
single word — funniest and most fitting wins.

> **feral**

## Why it should win

The internet was supposed to be a library, and it went feral. Nobody
is in charge, nothing is house-trained, and memes, scams, knowledge,
rage and cat videos all breed unchecked in the same wild. It is funny
by itself with no explanation needed, true of the internet as a whole
rather than one app or one mood, surprising — nobody's first reach is
"feral" — and it lands in one beat at five letters.

## How it works

`main.py` (Python 3, standard library only, no network) writes the
single word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`), with no trailing newline — the gate counts every
character. The run is deterministic: every run writes the same bytes.

```sh
python3 main.py
```
